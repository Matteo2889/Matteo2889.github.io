Conformité Debian

Objectif principal

Ma mission principale est d'assurer la conformité de systèmes Debian notamment en vérifiant :

  • Les packages, leur présence/absence et version
  • fichiers de configuration
Pour cela j'utilise l'outil Suse Manager avec des scripts bashs pour automatiser les vérifications, nottament avec des crons. Pour l'instant l'affichage se fait dans un fichier csv, ce format me permettra de réaliser un dashbord avec les outils de l'entreprises.

Conformité Debian

Objectif principal

Ma mission principale est d'assurer la conformité de systèmes Debian notamment en vérifiant :

  • Les packages, leur présence/absence et version
  • fichiers de configuration
Pour cela j'ai à ma disposition des outils comme SUSE Manager, Ansible avec Jenkins et Grafana. Initialement, j'ai utilisé SUSE Manager pour vérifier la conformité de systèmes Debian, l'outil est très complet mais il manque une page permettant de visualiser les résultats de manière globale. C'est pourquoi j'utilise désormais Ansible avec Jenkins, pour automatiser les vérifications de conformité afin de générer des rapports. Ces rapports permettent de réaliser des graphiques avec Grafana pour visualiser les résultats de manière globale.
